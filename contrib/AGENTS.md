# `contrib/` — Agent Guide 

This directory contains bundled third-party libraries and external utilities used by GAMBIT.
  
- **Avoid editing unless necessary:** Be reluctant to fix build or runtime issues by modifying code in `contrib/`. Prefer resolving issues in GAMBIT's own source files, CMake configuration, or wrapper layers first.
- **Check the package's license:** If modifying code in `contrib/<package>/` (or copying code into/out of it) is unavoidable, check that specific package's license first to ensure the change and any required notices/attribution comply with its terms.
